# HarvardX CS50P — CS50's Introduction to Programming with Python

This repository contains my coursework and programming practice completed while studying **HarvardX CS50's Introduction to Programming with Python (CS50P)**.

The repository documents my progression through the course, from fundamental Python syntax and control flow to testing, file handling, regular expressions, object-oriented programming, and my final project.

> **Note:** This repository is intended as my personal learning archive and portfolio of completed CS50P work.

## Course Overview

CS50P is Harvard University's introduction to programming with Python. The course focuses on problem solving and Python programming through lectures, exercises, problem sets, testing, and a final project.

Throughout the course, I practiced:

- Functions and variables
- Conditionals
- Loops
- Exceptions
- Python libraries
- Unit testing with `pytest`
- File I/O
- Regular expressions
- Object-oriented programming
- Program design and problem solving

## Final Project — The Locked Lab 🔐

My CS50P final project is **The Locked Lab**, a terminal-based escape-room game written in Python.

The player must solve four security puzzles in order to escape from a locked laboratory.

### Features

- Four different puzzle stages
- Caesar cipher decoding
- Numerical and logical reasoning
- Four-digit security-code challenge
- Power-switch logic puzzle
- Randomized puzzle selection
- Input validation
- Exception handling
- Attempt tracking
- Score calculation
- Player ranking
- Automated tests using `pytest`

The final project can be found in:

```text
project/
├── project.py
├── test_project.py
└── README.md
```

## Running the Programs

Most exercises can be run by navigating to their directory and executing the Python file.

For example:

```bash
cd "Week 0/einstein"
python einstein.py
```

To run the final project:

```bash
cd project
python project.py
```

To run its tests:

```bash
pytest test_project.py
```

## What I Learned

Completing CS50P strengthened my Python fundamentals and my approach to solving programming problems.

I learned how to break larger problems into smaller functions, write clearer and more reusable code, validate user input, handle exceptions, work with files and regular expressions, use classes and objects, and test program behavior with `pytest`.

The weekly exercises helped me build these skills progressively, while the final project gave me an opportunity to combine multiple concepts into a larger program designed from scratch.
